富文本能力边界

TipTap 扩展选择 — 严格控制，不做膨胀

✅ 启用扩展
· Bold (加粗)
· Italic (斜体)
· TextStyle (文字颜色)
· FontSize (字号调节)
· OrderedList (有序列表)
· BulletList (无序列表)
· TaskList (待办复选框)
· History (撤销/重做)
❌ 明确不做
· 图片 / 视频
· 表格
· 代码块
· 链接（自动识别但不做超链接）
· 引用块
· 水平线
· 附件 / 文件嵌入
💡 文字描边方案（解决对比度问题）
所有便签文字默认加 CSS text-shadow halo：暗色字 → text-shadow: 0 0 2px rgba(255,255,255,0.5)，亮色字 → text-shadow: 0 0 2px rgba(0,0,0,0.4)。用户自定义文字色时自动判断亮度选描边方向。
