第六节：数据安全 + 技术栈总览

纯本地 · 自动备份 · JSON 导出 · 技术选型确认

🔒 数据安全

💾 自动本地备份
· 频率：每日自动生成全量备份
· 数量：保留最近 7 份备份文件
· 格式：SQLite 完整副本 (.db 文件)
· 路径：默认 {data_path}/backups/，可自定义
· 命名：backup-2026-06-26.db
· 实现：Rust 后台线程，每日凌晨 3:00 执行
📤 手动导出 / 导入
· 导出格式：单个 JSON 文件
· 导出内容：所有表全量数据
· 导入模式：合并（不覆盖已有UUID）或覆盖
· 验证：导入前校验 JSON 结构完整性
· 路径：用户自选保存路径
🗑 回收站策略
· 删除 = 软删除（设置 deleted_at 时间戳）
· 回收站可恢复或永久删除
· 可设置自动清理周期（如 30 天后清空）
· 自动清理由 Rust 后台线程执行
🛡 隐私保证
· 纯本地运行，零网络请求
· 不上传任何数据到任何服务器
· 无遥测、无分析、无统计上报
· 安装包不含任何第三方网络 SDK

🛠 技术栈确认

运行 & 构建
运行时框架Tauri 2.x (Rust)
前端框架Vue 3 + Vite + TypeScript
富文本编辑器TipTap 核心版（8个启用扩展）
本地数据库SQLite (rusqlite + WAL 模式)
字体Inter (替代 figmaSans) + JetBrains Mono (替代 figmaMono)
打包体积目标< 5MB (Tauri 纯 Rust 二进制 + WebView 资源)
内存占用目标< 100MB 常驻
Tauri 插件
tauri-plugin-autostart开机自启动
tauri-plugin-global-shortcut全局快捷键 Ctrl+Alt+N
tauri-plugin-notification系统原生通知 + 提示音
tauri-plugin-window-state窗口状态记忆（补充自定义 SQLite 方案）
tauri-plugin-shell备份文件管理、打开文件所在目录
Vue 前端依赖
状态管理Pinia（窗口内本地状态，无需跨窗口同步）
TipTap 扩展@tiptap/starter-kit + @tiptap/extension-task-list + @tiptap/extension-task-item + @tiptap/extension-font-size + @tiptap/extension-text-style + @tiptap/extension-color
CSS 方案CSS Variables（映射 Figma design tokens）+ Scoped Styles
