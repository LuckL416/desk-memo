关键设计决策

🔗 单文件数据库

所有表存在一个 SQLite 文件。备份=复制文件。导出=SELECT 转 JSON。简单可靠。

⏱ Rust 侧独立计时线程

计时便签的倒计时在 Rust 后台线程运行，不依赖 Vue 窗口存活。窗口关闭 = 仅关闭视图，计时继续。

📡 Rust → Vue 单向推送

Rust 通过 Tauri 事件推送计时变化、提醒触发、便签变更给所有窗口。Vue 只负责消费和渲染。

💬 Vue → Rust 通过 invoke

用户编辑、新建、删除、设置等操作通过 Tauri invoke 调用 Rust 命令，Rust 写库后广播事件。

🪟 窗口状态记忆

每条便签的位置/大小/透明度/置顶模式存 SQLite。启动时 Rust 读取并重建所有窗口。

🔔 定时提醒 = Rust 定时器 + 系统通知

提醒时间存库，Rust 线程每秒检查，命中时调用 tauri-plugin-notification 弹出系统通知。

进程模型

一个 Tauri 进程，多个 WebView 窗口，一个 SQLite 连接（带 WAL 模式并发读）

桌面便签.exe (单一进程)
├── main.rs → 启动托盘 + 恢复窗口 + 初始化引擎
├── 后台线程: 计时线程 (1秒精度，检查所有活跃计时)
├── 后台线程: 提醒线程 (1分钟精度，检查所有提醒)
├── 后台线程: 备份线程 (每日定时，保留7份)
├── 后台线程: 自动保存线程 (debounced 批量写库)
├── WebView #1..N: 便签窗口 (每个独立 webview)
└── WebView: 管理面板 (按需创建)
